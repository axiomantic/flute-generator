# 🪈 Andean Condor Pasa Triple Flute (A4) with Arched Baroque Windway

Minor pentatonic triple flute in A4 with crowned arched windways inspired by Baroque recorders, focusing laminar airflow onto the center of the labium for singing upper harmonics.
